## 📌 Кратко о задачах

1. **Задача о накоплении воды (`trapping-rain-water`):**
   - Вычисляет, сколько воды может удержаться между столбиками разной высоты. Решено за один проход с подсчетом максимальных высот слева и справа.

2. **Моделирование очереди (`event-queue-simulation`):**
   - Простая модель: генерируются задачи со случайным временем прибытия и длительностью, сортируются по времени и по очереди «обрабатываются».

3. **Разбиение на группы (`partition-optimization`):**
   - Задача разложить числа по кучкам так, чтобы разница между ними была минимальной. Сравнивается полный перебор и жадный алгоритм.

4. **Класс треугольника (`geometry-triangle`):**
   - Пример ООП: закрытые поля, конструкторы (по умолчанию, с параметрами, копирования), деструктор и метод проверки неравенства треугольника.

5. **Класс дробей (`rational-fraction`):**
   - Работа с обыкновенными дробями: нахождение НОД по алгоритму Евклида, автоматическое сокращение и сложение/умножение через перегрузку операторов.
